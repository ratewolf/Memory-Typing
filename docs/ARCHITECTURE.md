# 아키텍처

## 계층 구조

소스는 `src/memory_typing` 아래의 다음 계층으로 분리한다.

- `domain`: 책, 장, 문장, 퀴즈, 학습 세션 같은 순수 데이터 모델과 도메인 개념을 정의한다.
  PySide6와 데이터베이스 구현에 의존하지 않는다.
- `core`: 타이핑 평가, 점수 계산, 학습 이벤트, 퀴즈 채점 및 복습 정책을 담당한다.
  UI 없이 단위 테스트할 수 있어야 한다.
- `storage`: SQLite 연결, 명시적인 스키마 변경, 저장소 구현을 담당한다. 다른 계층에 SQLite
  세부 구현이 새지 않도록 한다.
- `ui`: PySide6 창과 위젯을 담당한다. 사용자 입력을 core에 전달하고 결과를 표시하며,
  실질적인 학습 규칙을 자체적으로 구현하지 않는다.

의존성은 UI와 storage가 domain/core의 인터페이스와 모델을 사용하는 방향으로 유지한다.
core는 PySide6에 의존하지 않는다.

## 텍스트 모델

다음 세 값은 서로 다른 개념이며 절대로 혼용하지 않는다.

- `original_text`: 가져온 정본 원문이다. 학습 이벤트 표시를 만들기 위해 변경하거나 파괴하지
  않는다.
- `display_text`: 현재 학습자에게 보이는 문자열이다. 빈칸, 힌트, 초성 또는 숨김 효과가
  적용될 수 있다.
- `typed_text`: 학습자가 입력하고 IME가 확정한 문자열이다.

정답 평가는 최종적으로 `original_text` 또는 이벤트가 명시한 정답 사양을 기준으로 한다.
한국어 입력은 물리 키 이벤트가 아니라 Qt의 표준 텍스트 편집 및 확정 입력을 기준으로 처리한다.

## 확장 방향

학습 이벤트는 적격성 확인, 표시 준비, 답안 수신, 평가, 구조화된 결과 반환의 생명주기를 가진
추상화로 추가한다. 무작위 동작은 테스트에서 난수 생성기 또는 시드를 주입할 수 있게 한다.
SQLite 스키마 변경은 버전이 명확한 마이그레이션으로 관리하고 안정적인 콘텐츠 ID를 사용한다.
