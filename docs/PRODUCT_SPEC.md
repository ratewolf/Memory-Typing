# 제품 명세

## 제품 개요

Memory Typing은 사용자가 개인적으로 학습할 책이나 문서를 가져와 원문을 직접 입력하며
암기하는 한국어 중심의 오프라인 데스크톱 애플리케이션이다. 계정, 서버 또는 네트워크 없이
모든 콘텐츠와 학습 기록을 로컬에 보관한다.

## 핵심 학습 흐름

1. 개인 학습용 텍스트를 가져와 책과 장으로 구성한다.
2. 학습할 책과 장을 선택한다.
3. 원문을 보며 문장 단위로 따라 입력한다.
4. 입력 정확도, 진행률, 소요 시간 등 학습 상태를 기록한다.
5. 학습 도중 조건에 따라 빈칸 또는 문장 회상 이벤트를 제시한다.
6. 사용자가 직접 작성한 객관식 또는 단답형 퀴즈를 실행한다.
7. 타이핑, 이벤트, 퀴즈 결과를 로컬 데이터베이스에 저장한다.
8. 이후 누적 결과를 바탕으로 취약한 문장을 다시 학습한다.

## 콘텐츠 구조

콘텐츠는 `Book → Chapter → Paragraph → Sentence` 순서로 구성하며, 각 항목은 안정적인
식별자와 원문의 순서를 유지한다. 퀴즈는 책, 장 또는 선택적으로 특정 구절에 연결할 수 있다.

## 현재 구현 범위

현재 애플리케이션은 기본 샘플 또는 사용자가 가져온 JSON 콘텐츠에서 책과 장을 선택하고,
원문을 보며 문장 단위로 따라 입력할 수 있는 첫 번째 타이핑 학습 흐름을 제공한다. 문자별
정오, 정확도, 진행률을 표시하고 정확히 입력한 문장은 다음 문장으로 자동 이동한다.

구현된 기반은 다음과 같다.

- 안정적인 ID와 원문 순서를 보존하는 `Book → Chapter → Paragraph → Sentence` 도메인 모델
- 경계를 명시하는 JSON 버전 1 가져오기와 호환용 TXT 가져오기
- UI 프레임워크와 독립적인 타이핑 평가 및 문장 세션 로직
- 한국어 IME의 조합 상태를 관찰하면서 Qt 표준 텍스트 편집을 유지하는 입력 위젯
- 콘텐츠 계층, 학습 세션 및 문장 시도를 저장하고 조회하는 SQLite 스키마 버전 2와 저장소
- JSON으로 가져온 책의 재시작 후 복원과 완료한 문장 시도의 자동 기록
- 적격성 판단, 표시 준비, 답안 평가 및 구조화된 결과를 지원하는 학습 이벤트 추상화

학습 세션은 한 장에서 첫 입력이 시작될 때 생성한다. 문장을 원문과 정확히 일치하도록 완료하면
문장 ID, 확정 입력, 정확도, 문자 수, 경과 시간 및 타자 속도를 문장 시도로 저장하고, 마지막
문장이 완료되면 세션 완료 시간을 기록한다. 현재는 완료된 문장의 최종 평가 스냅샷만 저장하며,
입력 도중의 모든 오타 이력이나 중단된 입력 상태는 기록하지 않는다.

학습 이벤트 구조는 아직 실제 타이핑 화면에 연결되지 않았다. 현재 제공되는 이벤트 구현도
구조 검증을 위한 정확 일치 이벤트 하나뿐이다.

## 후속 개발 범위

- 저장된 학습 세션과 문장 시도를 조회하는 학습 이력 화면
- 입력 도중의 교정 과정 또는 누적 오류를 반영하는 시도 통계
- 이벤트 시도 기록
- 빈칸, 문장 회상, 키워드 회상, 이전 문장 회상 및 초성 힌트 이벤트
- 사용자 작성 객관식·단답형 퀴즈와 채점·결과 저장
- 학습 결과 화면과 문장별 취약도 통계
- 단순하고 교체 가능한 초기 복습 정책

## 제품 원칙

- 한국어를 기본 UI 언어로 사용한다.
- 높은 가독성과 키보드 중심의 집중된 학습 경험을 제공한다.
- 한국어 IME의 조합 중 문자열과 확정 문자열을 올바르게 다룬다.
- 원문 및 학습 기록을 사용자 요청 없이 삭제하지 않는다.
- 복습 정책은 초기에는 단순하게 유지하고 교체 가능하게 설계한다.
