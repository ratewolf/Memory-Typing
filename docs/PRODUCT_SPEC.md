# 제품 명세

## 제품 개요

Memory Typing은 사용자가 개인적으로 학습할 책이나 문서를 가져와 원문을 직접 입력하며
암기하는 한국어 중심의 오프라인 데스크톱 애플리케이션이다. 계정, 서버 또는 네트워크 없이
모든 콘텐츠와 학습 기록을 로컬에 보관한다.

## 핵심 학습 흐름

1. 개인 학습용 텍스트를 가져와 책과 장으로 구성한다.
2. 학습할 책과 장을 선택한다.
3. 원문을 보며 문장 단위로 따라 입력한다.
4. 입력 정확도, 진행률, 소요 시간 등 학습 상태를 기록한다.
5. 학습 도중 조건에 따라 빈칸 또는 문장 회상 이벤트를 제시한다.
6. 사용자가 직접 작성한 객관식 또는 단답형 퀴즈를 실행한다.
7. 타이핑, 이벤트, 퀴즈 결과를 로컬 데이터베이스에 저장한다.
8. 이후 누적 결과를 바탕으로 취약한 문장을 다시 학습한다.

## 콘텐츠 구조

콘텐츠는 `Book → Chapter → Paragraph → Sentence` 순서로 구성하며, 각 항목은 안정적인
식별자와 원문의 순서를 유지한다. 퀴즈는 책, 장 또는 선택적으로 특정 구절에 연결할 수 있다.

## 초기 범위

현재 단계는 프로젝트 기반과 빈 애플리케이션 창만 제공한다. 텍스트 가져오기, 타이핑 훈련,
학습 이벤트, 퀴즈, 결과 저장 및 복습 알고리즘은 후속 단계에서 구현한다.

## 제품 원칙

- 한국어를 기본 UI 언어로 사용한다.
- 높은 가독성과 키보드 중심의 집중된 학습 경험을 제공한다.
- 한국어 IME의 조합 중 문자열과 확정 문자열을 올바르게 다룬다.
- 원문 및 학습 기록을 사용자 요청 없이 삭제하지 않는다.
- 복습 정책은 초기에는 단순하게 유지하고 교체 가능하게 설계한다.
