# 수동 QA 체크리스트

## 실행 준비

1. 한국어 입력기가 설치된 Ubuntu/WSL 데스크톱 환경에서 애플리케이션을 실행한다.
2. 시작 화면에서 샘플 책과 장이 선택되고 현재 문장이 표시되는지 확인한다.
3. 필요하면 `JSON 가져오기`로 UTF-8 JSON 파일을 선택하고 가져온 책을 선택한다.

## 로컬 저장과 복원

- JSON 책을 가져온 뒤 애플리케이션을 종료하고 다시 실행한다.
- 가져온 책과 장이 선택 목록에 다시 표시되는지 확인한다.
- 한 장의 문장을 입력해 완료한 뒤 애플리케이션을 재시작해도 오류 없이 책이 열리는지 확인한다.
- 같은 ID의 JSON을 다시 가져오면 기존 책을 중복 추가하지 않고 한국어 경고를 표시하는지 확인한다.
- 기존 스키마 버전 1 데이터베이스가 있다면 시작 시 콘텐츠를 잃지 않고 버전 2로 갱신되는지
  확인한다.

## 한국어 두벌식 입력

- 입력기를 한국어 두벌식으로 전환하고 표시된 문장을 정상 속도로 입력한다.
- 조합 중인 자모가 별도 확정 문자로 중복 입력되지 않는지 확인한다.
- 마지막 한글 음절의 조합 문자열까지 원문과 일치하면 스페이스나 Enter 없이 확정되어 다음
  문장으로 넘어가는지 확인한다.
- 자동 확정 직후 다음 문장 입력창에 공백이나 이전 음절이 남지 않는지 확인한다.
- 마지막 음절의 조합 문자열이 원문과 다르면 자동 확정하거나 다음 문장으로 넘어가지 않는지
  확인한다.
- 정확 입력은 초록색, 잘못 입력한 위치는 빨간색 밑줄, 남은 부분은 회색으로 표시되는지 확인한다.

## 한글 조합 중 Backspace

- `한`, `값`, `읽`처럼 여러 자모로 조합되는 글자를 입력하다 Backspace를 누른다.
- Qt 입력기의 정상 조합 단계대로 자모가 제거되는지 확인한다.
- 조합 중 Backspace가 이전 문장 이동이나 자동 완료를 일으키지 않는지 확인한다.
- 글자를 확정한 뒤 Backspace로 지우고 다시 입력했을 때 정확도와 진행률이 복구되는지 확인한다.

## 한국어/영어 전환

- 한/영 전환 키로 입력 언어를 여러 번 바꾸며 혼합 언어 문장을 입력한다.
- 전환 직전의 한글 조합이 유실되거나 중복되지 않는지 확인한다.
- 영어 입력도 물리 키 단위가 아닌 편집 위젯의 확정 문자열로 정상 평가되는지 확인한다.

## 문장부호와 공백

- 마침표, 쉼표, 물음표, 느낌표와 문장 안의 공백을 원문대로 입력한다.
- 잘못된 공백이나 문장부호가 오류로 표시되는지 확인한다.
- Backspace로 교정하면 즉시 정확한 표시로 돌아오는지 확인한다.

## 문장 완료

- 마지막 한글 조합이 원문과 일치하지 않을 때는 문장이 넘어가지 않는지 확인한다.
- 마지막 조합 문자열 또는 문장부호까지 원문과 일치하면 다음 문장으로 한 번만 이동하는지
  확인한다.
- 다음 문장에서 입력창이 비워지고 포커스가 유지되는지 확인한다.
- 마지막 문장 완료 후 완료 메시지가 표시되고 입력창이 비활성화되는지 확인한다.

## 기록

운영체제, 데스크톱 환경, Qt/PySide6 버전, 입력기 종류(예: IBus 또는 Fcitx), 사용한 키보드
배열과 실패 재현 절차를 함께 기록한다. 실제 IME 조합 동작은 헤드리스 자동 테스트로 대체할 수
없으므로 지원 환경마다 이 체크리스트를 수행한다.
